# Build another specimen

1. Choose a species, life stage, and sex where relevant. Start with a name or a responsibly sourced photo. Record distinguishing features, body size, species-specific sources, comparative sources, and unresolved structures. Keep personal photos outside the repository. For Bugapedia suggestions, start with the [approved private build request](BUGAPEDIA.md).
2. Create a directory in `specimens` and add its ID and common name to `specimens/catalog.json`. Use the seven-spot folder as a worked example. Add a short reference brief and an authoring entry point called `build.py`. Local input files used during the build belong at the top level of the specimen directory.
3. Implement `build(root)` in Blender Python. Author in millimetres, with +Y toward the head and +Z upward. The shared pipeline creates the metric export root. Create one uniquely named empty directly beneath it for each selectable part. Parent visible meshes to that empty. Model exterior surfaces and separable organs, author natural materials, and embed any required textures. Name each independent articulation target under its own part.
4. Return the specimen record. Use the seven-spot manifest as the example. Include ID, common and scientific names, life stage, approximate length, model filename, first part, opening title and prompt, camera framing, systems with atlas colors, source IDs with titles and URLs, and the part list. Each part has an ID matching a Blender empty, a parent or null, system, common name, scientific term, two reading levels, source ID, and evidence label. A parent identifies an attachment that should move with its parent when dissected. Keep the attachment tree acyclic. Optional `landmarks` list the first labeled parts. Optional `spread` vectors specify how far each part moves in an exploded view, in displayed millimetres (x, up, rear), relative to its parent. The viewer derives radial offsets when a specimen omits these. For a long animal with a compact core, an optional `view.interiorFrameScale` below one brings its organs closer when the interior is selected. The dissection tray builds its labeled pictures directly from the model.
5. Add animated controls where appropriate. Each record names its open and close actions and may require a parent control to open first. Key poses between frames 1 and 49. The browser uses each part’s exported translation, rotation, scale, or morph tracks as a normalized control. Use a separate node for every independently movable structure. When several selectable pieces share a joint, give those parts a `control` ID pointing to the primary articulated part. Each animated piece exports its own tracks. The mantis builder uses this to keep the spines and foot moving with the shin while retaining separate labels. A specimen can supply its own `dragHint` and `gestureGuide` text.
6. Run `python3 rebuild.py YOUR-ID`. The command stages the output, opens a fresh Blender scene, reimports the GLB, and checks part IDs, selectable geometry, sources, and actions. Rebuild failure preserves the previously committed outputs.
7. Run the viewer and open `/?specimen=YOUR-ID`. Compare intact, opened, and interior views beside the sources. Check both palettes, safe closure order, readable part names, and reassembly on a narrow touch viewport. Record remaining differences and asset licenses in the species notes.

8. To add the specimen to Bugapedia, optionally include an original viewer render named `plate.webp` in the specimen directory. Run `npm run build:site` and check its new catalog card and shared specimen URL. Publish the reviewed model and notes. Keep the original observation in the private inbox.

## Add behavior

The ladybug and mantis builders include an optional `behavior.py`. Define `SEQUENCE` with a unique clip name, duration in seconds, a framing scale, a list of named actions with start times and observations, and motion references. Implement `pose(rig, t)` against the species' actual joints. Use the built-in frame rate and preserve continuity at chapter boundaries. The ladybug root travels forward and rises during flight. The mantis stays planted while its head and forelegs move.

The build saves separate behavior and articulation NLA tracks, marks the chapters in Blender, and exports both clips into the GLB. Rebuild and verify the specimen, play every action in the viewer, then switch back to an opened or dissected specimen and check its pose.
