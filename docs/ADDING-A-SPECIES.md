# Build another specimen

1. Choose a species, life stage, and sex where relevant. Start with a name or a responsibly sourced photo. Record distinguishing features, body size, species-specific sources, comparative sources, and unresolved structures. Keep personal photos outside the repository. The viewer has no photo intake.
2. Create a directory in `specimens` and add its ID and common name to `specimens/catalog.json`. Use the seven-spot folder as a worked example. Add a short reference brief and an authoring entry point called `build.py`. Local input files used during the build belong at the top level of the specimen directory.
3. Implement `build(root)` in Blender Python. Author in millimetres, with +Y toward the head and +Z upward. The shared pipeline creates the metric export root. Create one uniquely named empty directly beneath it for each selectable part. Parent visible meshes to that empty. Model exterior surfaces and separable organs, author natural materials, and embed any required textures. Name each independent articulation target under its own part.
4. Return the specimen record. Use the seven-spot manifest as the example. Include ID, common and scientific names, life stage, approximate length, model filename, first part, opening title and prompt, camera framing, systems with atlas colors, source IDs with titles and URLs, and the part list. Each part has an ID matching a Blender empty, a parent or null, system, common name, scientific term, two reading levels, source ID, and evidence label. A parent identifies an attachment that should move with its parent when dissected. Keep the attachment tree acyclic. Optional `landmarks` list the first labeled parts. Optional `spread` vectors specify how far each part moves in an exploded view, in displayed millimetres (x, up, rear), relative to its parent. The viewer derives radial offsets when a specimen omits these. The dissection tray builds its labeled pictures directly from the model.
5. Add animated controls where appropriate. Each record names its open and close actions and may require a parent control to open first. Key poses between frames 1 and 49. The browser uses each part’s exported translation, rotation, scale, or morph tracks as a normalized control. Use a separate node for every independently movable structure.
6. Run `python3 rebuild.py YOUR-ID`. The command stages the output, opens a fresh Blender scene, reimports the GLB, and checks part IDs, selectable geometry, sources, and actions. Rebuild failure preserves the previously committed outputs.
7. Run the viewer and open `/?specimen=YOUR-ID`. Compare intact, opened, and interior views beside the sources. Check both palettes, safe closure order, readable part names, and reassembly on a narrow touch viewport. Record remaining differences and asset licenses in the species notes.
